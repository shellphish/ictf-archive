# spamdb — iCTF 2005

**Competition:** iCTF 2005 "The Spam Museum" (December 2005, UCSB)
**Category:** web / pwn
**Format:** Attack-defense service

## Overview

A PHP XML-RPC service that manages a spam database. Clients interact via
XML-RPC calls to create accounts, add/query spam entries, and retrieve flags.
The service uses the phpxmlrpc library (xmlrpc.inc / xmlrpcs.inc).

## Architecture

```
http://<host>/~spamdb/cgi-bin/server.php   — XML-RPC endpoint
```

Exported XML-RPC methods (from `server.php`):
- `echotest(string)` → string
- `create_account(email)` → password
- `db_size()` → int
- (additional methods in `spamdb.inc`)

The account password is generated by `gen_passwd()` in `spamdb.inc`.
Flags are stored in the XML-RPC database as per-account entries.

## Vulnerability

The `phpwarninggenerator` method (in `xmlrpc_server_methods_container`) is a
dummy that generates a PHP warning by referencing an undefined variable `$b`.
This may reveal path and configuration information via PHP error output.

The password generation function (`gen_passwd()`) in `spamdb.inc` may be
weak or predictable, allowing an attacker to guess other accounts' passwords
and retrieve their stored flags.
