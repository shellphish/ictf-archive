## Writeup

This challenge is a bit of a warm-up for data-science challenges.
The file provided is a CSV with two columns: Temperature (in Celsius)
and Relative Humidity (in percentage). You must find the flag within
this data.

When given two-dimensional data, your first intuition should be
to plot it. We don't have a column for date and time. So probably
a line plot would not be a great choice. Instead, use a scatter
plot.

The scatter plot reveals the flag, spelled out with data points.
