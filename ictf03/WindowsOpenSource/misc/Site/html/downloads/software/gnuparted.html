GNU parted - Manipulates disk partitions

GNU Parted is a program that allows you to create, destroy, resize, move, and copy hard disk partitions. This is useful for creating space for new operating systems, reorganizing disk usage, and copying data to new hard disks.

The program currently supports ext2, ext3, and FAT (FAT16 and FAT32) filesystems and Linux swap devices, and MS-DOS disk labels.
