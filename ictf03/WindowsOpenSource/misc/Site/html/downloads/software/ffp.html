Ffp - Free Film Project

The GNU Free Film Project's aim is to write to write a complete suite of utilities which can serve as a free and complete virtual film studio. The project is currently in the planning stage; design notes, a to do list, and a list of individual projects for which some code has been written are available on ffp's home page.

Code has been started for the following programs: xyz2rgb, a graphics filter; OnCue, a lighting control program; and StoryBoard Model Scripting Tool and Scriptwriter, both scripting utilities. Current efforts concentrate on distributed computing, video editing, and animation rendering, although coding continues on all modules.

The Free Film project (http://www.geocities.com/ResearchTriangle/Facility/6309/faq.html) plans to use this software to create entirely free movies with all ontent released uder the GPL.
