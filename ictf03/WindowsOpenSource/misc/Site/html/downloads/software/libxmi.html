libxmi - Library for rasterizing 2-D vector graphics

A standalone C/C++ function lib for rasterizing 2-D vector graphics. The program can draw 2-D vector graphics primitives, including wide polygonal line and circular and elliptical arcs, onto a user-supplied matrix of pixels. Sophisticated line styles, such as multicolored dashing patterns, can be specified. There is also support for filling and texturing polygons.

The program is based on the vector graphics code found in most X windows system servers, but despite its origins, libxmi is completely decoupled from X11. It draws vector graphics onto a user-supplied matrix of pixels, not onto an on-screen window, and uses its own two-stage graphics pipeline.
