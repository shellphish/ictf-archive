Dumb - Free engine for running doom worlds

'Dumb' is a 3D game engine for GNU/Linux. 'Dumb' uses a gamefile format compatible with ID Software's Doom engine; it can in fact play Doom and related games.

There are performance differences, however. For example, 'Dumb' adds several new lumps to game wads to control texture animation and object behavior, but they don't have to be compiled into the game. Therefore, a single binary of 'dumb' can play a variety of different games. Also, you can pan the camera up and down, display textures at various resolutions, tile textures vertically at any power-of-two height between 4 and 1024, and tile horizontally at any width.

You can play Doom, Doom II, and Heretic, although not all features are implemented. You can also play any of the gamefile patches (PWADs) available for these games, although you need the main gamefile (IWAD) for each game. You can also create your own levels using the level editor XWad.
