GNU Enterprise - Unfinished project to develop a complete ERP system

GNU Enterprise is developing tools to build portable database applications, and a complete ERP system building on these tools.

While some of the tools (like a data-aware user forms interface or a reporting system) are in an usable state, the packages of the actual ERP system are in planning state. An alpha version of the first component, the GNU Enterprise Application Server, has already been released. Other components are actively being worked on.
