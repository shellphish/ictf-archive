GNU sauce - Anti-spam server

Software Against Unsolicited Commercial Email is an SMTP frontend written to fight spam and promote good system configuration and administration. It sits between the Internet and your actual mail software. The program is extremely aggressive in checking incoming email and its sources; if it discovers any problems, it will not accept the mail.

Mail from previously unknown sources is delayed to test for bait addresses or cancelled accounts. When mail is sent to a bait address its sources are blacklisted. as per the developer, the program delays mail from new sites and senders, and will bounce sites that are misconfigured, whether or not they are spam.
