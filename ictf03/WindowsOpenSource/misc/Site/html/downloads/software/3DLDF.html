3DLDF - 3D drawing package

'3DLDF' is a 3D graphics package with MetaPost output. It is written in C++ using CWEB and includes documentation. 3DLDF currently doesn't include an input routine, so user code must be written in C++, compiled, and linked with the rest of the program.
