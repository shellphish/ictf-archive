Source-highlight - Turns source code into a file with syntax highlighting

This is a collection of two established and stable programs, GNU cpp2html and GNU java2html, that, given a Java, JavaScript, C/C++, Perl, Prolog, Php3, Python, Flex, changelog, or Ruby source code file, translates that file into an HTML, XHTML or ANSI color escape sequences file with syntax highlighting. Later versions will include other programs such as java2latex, etc.
