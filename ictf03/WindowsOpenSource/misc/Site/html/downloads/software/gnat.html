GNAT - GNAT is a complete Ada95 compilation system

GNAT is a free, complete compiler for Ada95, integrated into the GCC compiler system.

Ada is a language perfect for large and complex systems, or in long-term projects where reusable and maintainable code is essential. GNAT now includes GLIDE, an integrated development environment that includes an editor and debugger and supports multiple graphical debuggers. Support for larger projects is enhsnced by (on some systems) elimination of command line lenghts limits and easier ways to enter a long list of directories into the project file.
