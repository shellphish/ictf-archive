fhp - m4 macro for creating Web pages

'fhp' is a set of m4 macros for creating Web pages that conform to GNU standards. It automatically generates an HTML skeleton and the table of contents, and adds an link to GNU on every page. Web pages are easily generated with a Makefile. This project was formerly known as GNU ml.
