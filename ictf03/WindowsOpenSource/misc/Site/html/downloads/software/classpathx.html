GNU Classspathx - Unfinished free implementation of the Java extension libraries

A complete implementation of java extension libraries froma activation to xml. Packages currently under development include javabeans activation framework, javabean infobus, java cryptology, java mail, jaxp, net extensions, and a servlet API.

Development is through Savannah, the GNU CVS repository.
