Nano - Pico clone for *NIX

GNU nano is a small and user friendly text editor. It has GNU autoconf support, goto line and replace functions, an interactive replace function and spell checker, auto-indent support, slang curses-wrpper support, variable tab width, regular expression sarch and replace, and toggles for command line flags that can be used from within the editor.
