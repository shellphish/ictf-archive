GnuPod - Lets you use an iPod under GNU/Linux

GnuPod is a collection of Perl scripts that let users use an iPod under GNU/Linux. The latest version has UNICODE support. You can edit the GNUtunesDB with an Unicode editor (ie yudit), and converting an 'non-latin1' iTunesDB also works well.
