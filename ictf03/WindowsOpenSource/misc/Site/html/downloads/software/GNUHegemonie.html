GNU Hegemonie - Multiplayer 3D game inspired by XPilot but set in a maritime world

The gameplay of Hegemonie will to some extent be like XPilot but in a water world, in peculiar landscapes. This will be a 3d game, network oriented. In Hegemonie you can equip your ship, increase your level, buy items... We aim at developing a game as accesible for the novice as it is challenging for the experienced gamer.

Technically speaking we will base our development on SDL, OpenGL, Objective-C and the GNUstep technologies. All the configuration files (like maps, types of boats, types of bonus...) will use Guile for extensibility and simplicity.

The project, while still in the planning stage, in being actively worked on although no code has yet been released.
