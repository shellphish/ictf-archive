GaMa - Geodetic network adjustment program

GNU Gama is a project dedicated to adjustment of _geodetic networks_. It has been started at the department of mapping and cartography, faculty of Civil Engineering, Czech Technical University in Prague (CTU); the name is an acronym for _geodesy and mapping_. GNU Gama is based on a C++ library of geodetic classes and functions `libgama' and a small C++ template matrix library `gmatvec'.

The stable branch of the project is limited to network adjustment in a local coordinate system and its functionality is represented by the program `gama-local, ' which adjusts geodetic (free) networks of observed distances, directions, angles, height differences, 3D vectors and observed coordinates (coordinates with given variance-covariance matrix). In the new development branch the adjustment model is based on geocentric coordinate system (adjustment model on ellipsoid). Its functionality will be represented by the program `gama-g3'.
