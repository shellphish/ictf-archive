CLISP - ANSI Common Lisp compiler, debugger, and interpreter

CLISP is a Common Lisp implementation. It mostly supports the Lisp described in the ANSI Common LISP standard. The program includes an interpreter, a compiler, a debugger, most of CLOS, a foreign language interface and a socket interface. An X11 interface is available through CLX and Garnet. It runs on microcomputers and PCs, as well as on *nix workstations. It needs only 2 MB of RAM, implements most of the ANSI standard, and can call your preferred editor.

The user interface comes in German, English, Spanish, French, Dutch and Russian, and can be changed at run time.
