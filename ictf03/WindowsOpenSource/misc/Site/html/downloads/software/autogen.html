Autogen - Automated program and text generation

Autogen is a tool for generating program files that contain repetitive text with varied substitutions. It simplifies maintenance of programs with large amounts of repetitive text. This is particularly valuable if there are several blocks of such text that must be kept synchronized. The following programs are also included:

AutoOpts completely automates the process of handling command line, environment and donfig file options, including usage text, man pages, and the invoking section of an info doc.

getdefs extracts AutoGen definitions from stylized comments embedded in source code.

columns tabularizes lists for improved output appearance. See also ls(1).

AutoXDR is an affiliated download. NFSv4 specifies that its remote procedure calls be batched. Using an enhanced XDR specification and the AutoXDR templates, AutoGen generates all the grunge code for marshalling and unmarshalling the arguments on both sides of the RPC request.

AutoFSM, where it is possible to determine a state transition type (token code) without reference to the current state, will produce a transition table and prototype finite state machine.

xml2ag lets AutoGen use any XML file as if it were a set of AutoGen definitions, which greatly facilitates creating useable text files from XML.
