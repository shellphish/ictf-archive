Gnats - Bug tracking system

GNATS organizes the large volume of email that flows between end users and software maintainers by defining a database made up of archived and indexed email messages. It consists of several utilities which, when used together, formulate and administer a database of Problem Reports grouped by site-defined "problem categories." It lets a support organization track problems in an organized manner through acting as an active field archive for field-separated textual data submitted through email.

There are several front end interfaces, including command line, Emacs, and TCL/Tk. There are also a number of Web interfaces (CGI) written in languages like Python and Perl.
