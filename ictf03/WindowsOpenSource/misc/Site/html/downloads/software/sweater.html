Sweater - Generic database front end

Sweater is a generic database front end tool. The goal is to be able to use sweater to communicate with any SQL database backend (using unixODBC) and to be toolkit independent by using the GNUTS library.

Sweater is not currently available for download via ftp. You must get it from the GNU CVS server. Sweater's module name is 'sweater'. You can also access the CVS repository using the CVSweb interface.
