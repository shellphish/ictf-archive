Dr genius - Interactive geometry program and calculator

Dr. Genius Refers to Geometric Exploration and Numeric Intuitive User System. It is a merge of two projects: Dr. Geo and the Genius calculator.

The Genius Calculator is a multiple precision calculator with an interpreted language, GEL, plus a large mathematical library written in GEL. Dr. Geo is a vector drawing software with mathematical constraints- we call this "interactive geometry."
