cfs-el - Frontend for CFS

'cfs-el' is an Emacs frontend for CFS (Cryptographic File System). It uses the Emacs customization facilities for setting preferences; you can use the command @command{M-x customize-group RET cfs RET} to access the cfs customization group.

Before using cfs-el, it must be loaded into your current Emacs image.
