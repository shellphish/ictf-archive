Window Maker - Window manager for X Window System

Window Manager is a fully configurable window manager for the X window system. Its features include: --ICCCM compliant --support for GNOME, GNUstep, and KDE --localization support --drag and drop support --flexible menus for launching applications --treat windows belonging to a single application as a whole --can quickly access multiple workspaces --supports many kinds of decoration textures --good functionality vs. resource consumption ratio --graphically configurable --many styles and textures for window and icon decorations While designed to give additional integration support to the GNUStep desktop, Windowmaker also works with GNOME and KDE.
