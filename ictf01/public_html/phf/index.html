phf Vulnerability

Archive Author

  • Giovanni Vigna

Description

The phf CGI program contains a bug in the argument parsing procedure. By inserting new lines in the script parameters it is possible to execute a command as the user running the WWW server. For example, it is possible to retrieve the password file with the following GET request:

    GET /cgi-bin/phf?Qalias=x%0a/bin/cat%20/etc/passwd

Exploit

To exploit this vulnerability, we developed the phf-attack program that takes as inputs the host/port where the vulnerable Web server is located, and the list of commands to be executed. The program packages the commands in a GET request and then connects to the vulnerable server and performs the exploit.

  • phf-attack.c Exploit for the phf bug.

Vulnerable Software

The phf.c program was originally distributed with the NCSA 1.3 web server. The code can be compiled separately and put on a web server cgi-bin directory to test the exploit.

  • phf.c: The phf source
  • util.c: Additional routines needed to compile the program.

To compile the phf CGI program (tested on Linux RedHat 6.2):

    % gcc -c util.c -o util.o 
    % gcc -c phf.c -o phf.o
    % gcc util.o phf.o -o phf

To install the phf CGI program, simply copy the program to the CGI directory of any web server.

Manifestation

The attack can be detected by examining the contents of the TCP connection to the server. The following two links provide tcpdump logs for an attack and a normal invocation of the CGI program

  • tcpdump-phf tcpdump trace of the attack.
  • tcpdump-phf-normal tcpdump trace of a normal request.
