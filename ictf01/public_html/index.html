290I - Network Security and Intrusion Detection

Abstract

Network security has become part of everyday life. Security problems may impact practical aspects of our lives. Even though there is a considerable corpus of knowledge about tools and techniques to protect networks, information about what are the actual vulnerabilities and how they are exploited is not generally available. This situation hampers the effectiveness of security research and practice. Understanding the details of network attacks is a prerequisite for the design and implementation of secure systems.

This course presents the principal protocols and applications that are used in the Internet today, discussing in detail the related vulnerabilities and how they are exploited. For each vulnerability, possible protection and detection techniques are examined.

The course mixes a practical character, with a hands-on approach, with a discussion of the current research in the field. Participants will learn how the security of networks can be violated and how such violations can be detected and prevented. The course includes also red-team/blue-team exercises in a protected environment, where the knowledge about attacks and defenses will be validated in the field.

Ethical issues will also be discussed.

Prerequisites

The course requires good programming/development skills, a basic background in operating systems, and some basic knowledge about networks.

Topics

  • Introduction, history, ethics
  • Brief introduction to cryptography
  • TCP/IP security (spoofing, hijacking, sequence number guessing, denial-of-service attacks)
  • Network discovery/vulnerability scanning: techniques and tools (portscans, ping sweeps)
  • Web security
  • Operating system security and vulnerabilities (UNIX, NT, buffer overflows)
  • Distributed systems security (RPC, NIS, Kerberos)
  • Firewalls and traffic filtering
  • Network-based intrusion detection systems
  • Host-based intrusion detection systems
