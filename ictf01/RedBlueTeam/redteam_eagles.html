Mission

We were supposed to scan the 128.111.54/24 network from a machine outside the network, that is, find out which hosts existed on the target network. Also, we were going to find the corresponding MAC addresses, and determine which operating systems were installed on the different machines. We should provide as much information as possible about the OS, both the kernel version and the distributor, if possible. Since we were not supposed to use any a priori knowledge, we had to do topology scanning as well.

The responsibilities that each subgroup member had in the beginning: 

	Ahmad: 	 nmap IP scan, script for traceroute.

	Minghao: fragmentation IP scan, look into topology, Queso.

During the preparation period, we modified each member's responsibilities, because things did not turn out to be exactly what we believed them to be in the beginning. In the next paragraph, "Preparation", there is an overview of who ended up doing what.


Preparation

Planned activities for finding...: 

IP: inverse mapping using ICMP.
MAC: we had no idea in the beginning, but discovered snmpwalk after a while.
OS: Queso.
Topology: traceroute.
We ended up with these activities/methods for finding...: 
IP: inverse mapping using nemesis-icmp, and run tcpdump to analyze the response, and also snmpwalk.
MAC: snmpwalk 
OS: Nmap.
Topology: WhatsUp Gold.
These are the tools we have found on the Internet, and not developed ourselves:
  • Nemesis, a tool for creating packets. We used it for creating 'echo reply' packets.
  • Nmap, a tool for network mapping. We used it for OS fingerprinting.
  • WhatsUp Gold 6.0, a tool for topology scanning. Runs on NT machines.
  • tcpdump, a tool for analyzing packets on the network. We used it for analyzing the response on the inverse mapping.
  • snmpwalk, a tool for looking into a network configuration on a gateway. We used it for finding the MAC addresses of the existing hosts.
  • JohnTheRipper, a tool for password cracking.
These are the tools/programs/scripts we have developed:
  • discover: a script that sends 'echo replies' to all IP addresses (128.111.54.(2-254) on the target network using nemesis-icmp. Developed by Maria.
  • icmplistener: a script that runs tcpdump during the runtime of discover and analyzes the response from the target machines. Developed by Maria.
  • top: a collection of scripts that runs snmpwalk and nmap, and prints the IPs, MACs, and OSs of all detected hosts to a file, which is passed on to the next group. Developed by Ahmad and Minghao.
  • run: a script that runs nmap to do IP scanning. Developed by Kim.

Evaluation

We accomplished our mission very well. We were able to find the IPs and the corresponding MACs in a short amount of time. It took us longer to find the OSs because of the fake replies generated by the blue team.
We also found the topology later. Nobody ever asked for the topology, though.

Despite of an initial problem in using the scripts for inverse mapping, we executed our plan of attack successfully using the script 'top'. We were also prepared to run tools manually in case we needed to.
The problem with the inverse mapping was that we did not get any response from the target machines due to some icmp filtering, probably.

We should have run 'top' several times, because the blue team changed the IP mappings after we passed our initial findings to the next subgroups.

We saved the findings in a file accessible by the next subgroup in a format we previously agreed on. There were no problems with interfacing to the next group.

The tools we used were very helpful and powerful. We tried out different tools for network scanning to find which tools were most suitable for our mission, and finally we decided to use the above mentioned tools.
We had a hard time finding a good tool for topology scanning, but at last we found WhatsUp Gold, which is a NT-based tool using snmp and ICMP scanning.

We think that this exercise should have taken place earlier in the quarter, and not the last week before the exams and project deadlines. One or two weeks earlier would be fine.


Miscellaneous

The tools we have tried out, are Firewalk, Tracerx, Nemesis, Nmap, snmpwalk, ping, traceroute, tcpdump, SING (Send ICMP Nasty Garbage), Queso, WhatsUp Gold, and rpcinfo.
We also considered using different techniques for IP scanning, such as bad header fields, incomplete fragmentation, non-echo ICMP packets. For OS fingerprinting we considered using passive fingerprinting.

During the exercise, we were not able to run snmpwalk from packard to the gateway on the target network, so we had to run it from a local machine in the CSIL. And also, we had the problem with not getting all the ICMP response from the inverse mapping. So maybe the RSL network, 128.111.48.x is too strictly configured to be a good network to use in such an exercise?
