LINUX System installation
1) Update the /etc/sysconfig/network-scripts/ifcfg-eth0 file with the right parameters
DEVICE=eth0
BOOTPROTO=static
IPADDR=192.168.1.XX
NETMASK=255.255.255.0
NETWORK=192.168.1.0
BROADCAST=192.168.1.255
GATEWAY=192.168.1.254
ONBOOT=YES
2) Update the /etc/hosts file with the one provided on the diskette
# cp /dev/fd0/hosts.testbed /etc/hosts
3) Append to the /etc/passwd file the contents of the passwd.add file provided on the diskette
   (Remember to check that the password file does not already contain the accounts)
# cat /dev/fd0/passwd.add >> /etc/passwd
4) Create the users home dirs by using the script on the diskette
# cat /dev/fd0/passwd.add | /dev/fd0/accounts.pl | /bin/sh
5) Update the /etc/resolv.conf file with the one provided on the disk
# cp /dev/fd0/resolv.conf.testbed /etc/resolv.conf
