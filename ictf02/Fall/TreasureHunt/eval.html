Treasure Hunt Evaluation Sheet

The first team that achieves the task gets 5 points. If the other team completes the task within the specified time, it gets 3 points. If the time elapses and the team is not able to complete the task, then a cheat-sheet will be provided so that the task can be completed, but only 1 point will be assigned. If the task is not completed with the help of a cheat sheet then a solution will be given. The instructions must be followed and the task must be completed anyway, even if no points will be assigned.
