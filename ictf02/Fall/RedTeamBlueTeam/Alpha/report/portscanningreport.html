Mission

        Our mission was to find open ports on the other team’s machines. In other words, port scanning.

Preparation

        We started off with a survey of the available port scanners and packet building tools. Nmap and hping were the ones that we decided we would use.

We started off by examining how we could do port scans stealthly. Nmap almost always trigged off alerts. We noticed that injecting a TCP SYN packet to a target host using hping and observing the response was the best way to do a port scan. The default snort installation on our machines could find a FIN,XMAS or NULL TCP scan but was not triggered off by the TCP SYN packets that we sent. Therefore we decided on using hping to generate TCP SYN packets and observe the response to decide on the port status.

          We did a survey on the most common TCP ports. We wrote scripts which would take 3 arguments namely the target port, a spoofed ip address (from our part of the subnet) and the source port and send TCP SYN packets to the target under the spoofed ip address. We planned to do the scan on a target in three phases. Phase one of the scan would consist of running a script which would send SYNs to 10 of the most common ports and the response would be studied.  Phase two consisted of running a script which would scan another 20 most common ports. The last phase was optional and it was to run Nmap through whatever ports that remained.

          We also wrote scripts to do UDP scan using raw UDP packets produced by hping.  We used the above strategy for the UDP scan as well.

Execution

        The IPM group gave us the ip addresses of hosts which were alive. We ran our scripts and figured out the list of common ports which were open. This information was passed on to the OS finger printing and service mapping group members.

Evaluation

        It was a pleasure to see SYN ACKS from a large number of the ‘common’ services that we had picked. We were able to successfully probe the open ports for all the 6 machines whose ip addresses were handed on to us by the IP mapping group.
