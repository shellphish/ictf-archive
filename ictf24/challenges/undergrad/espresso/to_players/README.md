# Espresso

Hello! In this challenge, your task is to create an adversarial example that tricks the model into generating a specific result—in this case, making the model think that dark soy sauce is espresso!

Please refer to the challenge implementation details in the [\_\_init\_\_.py](./__init__.py) file. Once you've figured out a solution and successfully generated an image, you can submit your result using the [submit_solution.py](./submit_solution.py) utility script.

```bash
python3 submit_solution.py --ip <IP> --port <PORT> --image <PATH_TO_YOUR_IMAGE>
```

Good luck, and happy hacking!
