# iCTF 2007 — Copyright Mafia: Copyright Registry

**Edition:** iCTF 2007 | **Category:** web | **Language:** PHP

## Description
Copyright registration portal with file upload (upload.php), account management,
login, and star artist tracking.

## Run
```bash
docker build -t ictf07-copyright . && docker run -p 8081:80 ictf07-copyright
```
