# Pickle's Pickles: An Origin Story

**Category:** Misc | **Points:** 500

## Description

You've arrived at Pickle's Pickles. I've heard he has the best pickles around. However he has quite a strange way of pickling his pickles.

## Setup

```bash
docker compose up --build
```

Connect with: `nc localhost 39723`

## Challenge Structure

Interactive TCP service (Python). Presents a menu-driven interface with three options: serialize a new object (pickle), deserialize a provided payload (unpickle), or exit.
