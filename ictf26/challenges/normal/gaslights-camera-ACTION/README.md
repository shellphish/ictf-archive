# Gaslights, Camera, ACTION

**Category:** Forensics | **Points:** 500

## Description

Dr. Light claims he sent out the CTF requirements months ago, but nobody in the lab remembers seeing it until today. He's provided his original "iCTF Planning Document" to prove he isn't losing his mind.

Can you examine the document he provided and find the flag?

## Files

- `iCTF_Planning_Document_2026_FINAL.pdf` — the planning document

## Challenge Structure

Static challenge with a single PDF file — no interactive service. The document is a planning report that may contain more information than is immediately visible.
