# Don't Lose Your Head

> A chaotic cat appreciation website. Somewhere in the noise, there's a flag.
> Don't lose your head trying to find it.

**Category:** Web | **Difficulty:** Medium-Hard

## Description

You stumble upon the internet's most important cat website. It's loud, it's
colorful, and it's full of cats. Somewhere behind the chaos, there's an admin
panel with the flag. But you're not an admin... right?

Don't lose your head. The answer is staring you in the face (or rather,
in the headers).

## Setup

```bash
docker compose up --build
```

Port **3000**.
