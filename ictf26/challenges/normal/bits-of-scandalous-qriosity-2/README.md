# Bits of Scan-dalous QRiosity Part 2

**Category:** Forensics | **Points:** 500

## Description

When multiple images of the same scene are combined, random noise cancels out while stable signals are reinforced. Hidden data embedded in individual frames becomes recoverable once the noise is removed.

Can you find the flag?

> **Note:** the flag format for this challenge is `iCTF={flag}` instead of `ictf{flag}`.

## Files

- `CueAres.zip` — archive containing multiple image frames

## Challenge Structure

Static challenge with a ZIP archive containing multiple PNG frames of the same scene — no interactive service. The challenge requires offline processing and analysis of the image set.
