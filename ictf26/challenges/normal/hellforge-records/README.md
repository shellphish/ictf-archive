# Hellforge Records

**Category:** Web | **Points:** 500

## Description

Hellforge Records is the most brutal online metal CD shop in the underground. They recently launched a loyalty program with premium coupons and exclusive albums. Can you find a way to get the ultra-rare album?

## Setup

```bash
docker compose up --build
```

Service available at `http://localhost:5000`.

## Challenge Structure

Flask web application backed by a SQLite database. Exposes a metal CD store with a product catalog, shopping cart, checkout flow, a loyalty points system, and a QR code scanner for redeeming promotional codes.
