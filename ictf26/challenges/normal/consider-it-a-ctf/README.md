# Consider it a CTF...

**Category:** Forensics | **Points:** 500

## Description

Professor Light insists that the CTF announcement was shared weeks ago. He has provided the "original" announcement as proof. If you don't remember seeing it, that's clearly on you.

Fortunately, version control systems tend to keep careful records. Can you recover what was originally written?

## Files

- `announcement.zip` — announcement materials

## Challenge Structure

Static challenge with a ZIP archive containing a git repository — no interactive service. The repository holds an announcement document whose full history can be inspected offline.
