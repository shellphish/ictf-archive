# Bits of Scan-dalous QRiosity Part 1

**Category:** Forensics | **Points:** 500

## Description

Digital images are grids of pixels, each storing red, green, and blue values from 0 to 255. By making subtle changes to pixel values that are imperceptible to the human eye, information can be hidden inside an ordinary-looking image.

Can you "see" the flag?

> **Note:** the flag format for this challenge is `iCTF={flag}` instead of `ictf{flag}`.

## Files

- `1obfus.png` — image file

## Challenge Structure

Static challenge with a single PNG image — no interactive service. The challenge requires offline analysis of pixel data in the provided image file.
