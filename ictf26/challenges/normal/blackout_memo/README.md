# Blackout Memo

**Category:** Forensics | **Points:** 500

## Description

A confidential internal memo was sanitized just hours before release. Recover the redacted content from the provided PDF and submit the flag.

## Files

- `src/confidential_email.pdf` — the redacted memo

## Challenge Structure

Static challenge with a single PDF file — no interactive service. The document contains visually redacted sections whose underlying content must be recovered through offline analysis.
