# iCTF 2009 — Vulnerable System Service

**Category:** Binary / Attack-Defense
**Tags:** binary, service, attack-defense

## Description

The traditional attack-defense component of iCTF 2009. Each team's Linux VM
ran a service daemon controlled via `/etc/init.d/vulnerable_system_service`.
Teams had to simultaneously:

- Find and exploit vulnerabilities in rival teams' instances
- Patch their own instance without taking it down

This coexisted with the novel browser-exploitation format that dominated
the competition.

## Source

Source not preserved. The binary may be recoverable from the team VM images
stored in `Virtual Machine/` (Windows XP dev environment — the service
itself ran on a separate Linux VM per team).
