The Encryption Test Process

Please try to download these files and see if your are able to decrypt them. Downloading the actual image will follow a similar process.

.
  • downloadtest.tgz.gpg
  • downloadtest.tgz.gpg.md5

Please download both files. Then execute:

% md5sum downloadtest.tgz.gpg

Compare the output of the MD5 program with the contents of the downloadtest.tgz.gpg.md5 file. If they are different, you have a problem. The file you downloaded might be corrupted, for example.

If the output of the MD5 checksum and the content of the file match, then you can decrypt the file:

% gpg downloadtest.tgz.gpg

You will be asked for a password. Use "foobar". This will decrypt the archive and create a file called downloadtest.tgz.

In the real competition, the password to decrypt the VMWare image will be disclosed exactly at 10am, PST. Therefore you will not be able to try the image before then.

To check if everything is fine you can also decompress the archive

% tar xvzf downloadtest.tgz

You should now have a directory with a couple of test files.
