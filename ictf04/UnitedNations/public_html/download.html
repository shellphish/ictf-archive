VMWare Image

This page will provide access to the VMWare image of the competition.

These are the files:

  • iCTF.tgz.gpg (~500MB)
  • iCTF.tgz.gpg.md5

Please download both files. Then execute:

% md5sum iCTF.tgz.gpg

Compare the output with the contents of the iCTF.tgz.gpg.md5 file. If they are different, you have a problem. The file you downloaded might be corrupted, for example.

If the output of the MD5 program and the content of the file match, then you can decrypt the image:

% gpg iCTF.tgz.gpg

You will be asked for a password. The password to decrypt the VMWare image will be disclosed exactly at 10am, PST. Therefore you will not be able to try the image before then.

Once you decrypt the image you can also open the archive

% tar xvzf iCTF.tgz

You should now have a directory with the VMware test files.
