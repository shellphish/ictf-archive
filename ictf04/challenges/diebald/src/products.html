The Die-Bald Corporation provide a wide range of security products. What follows is just a sample of the applications that Die-Bald is proud to deliver.

The UN Voter Registration System

Using this secure web application user can register to vote in the World-Wide Election to be held on December 3rd, 2014. A user is able to upload his/her personal data and to review it an any time.

The security of the system is guaranteed by extensive security audits on the application code, and on the use of strong authentication mechanisms, such as the World-Wide ID and a password.

The UN Internet Voting System

Users world-wide can securely vote using this simple application. By downloading the client application users can vote by simply passing, as command line parameters, their World-Wide id (--wwid option), the vote for the World President (--vote option), and the Internet voting host to contact (--host option). It is also possible to contact a specific port using the --port option.

All the communications between client and server are encrypted using a in-house developed secret algorithm, based on the eXtended Orbital Recursion algorithm. This algorithm is a Die-Bald industrial secret and is provably impossible to break.

The application is available for Linux system only, since it is nowadays the platform most widely used throughout the world.

The Voter Password Verification

This Internet-based service allows users to check the strength of their password before they use it in the voter registration application.

Password are verified using the Globally Redundant Evaluator of Password, an algorithm that checks for password using artificial intelligence techniques.

Users can connent to the service using a simple telnet application. By using the STORE [username] [word] command users can update their personal dictionary. The personal dictionary can be viewed at any time using the DICT [username] command. A password can be checked for strength using the CHECK [username] [password] command.
