Live Security Exercises at UCSB

This is a summary of the different live security exercises carried out at UCSB as part of the graduate class on network security taught by Giovanni Vigna.

Winter 2001

The security class was first offered in Winter 2001. This edition of the class included a "Red Team/Blue Team" exercise. The class was divided into two groups: the Red Team was responsible for attacking a set of hosts (no virtualization was used), while the Blue Team was responsible for protecting the hosts.

The description of this exercise can be found here

Spring 2002

The second edition of the class included a "Red Team/Blue Team" exercise where the two teams had to both attack and defend a set of hosts. As for the previous exercise, no virtualization was used and the hosts involved in the exercise were actual PCs.

The description of this exercise can be found here

Fall 2002

In the third edition of the class there were two live exercise. The first one was a "Scanning Exercise" and the second one was a "Treasure Hunt".

Scanning Competition

In this exercise, each team has to gather the maximum amount of information about a number of hosts. No attacks that would compromise the hosts could be performed. The goal of this exercise was to focus on scanning and scanning detection technique.

The description of this exercise can be found here

The Treasure Hunt Exercise

In this exercise two teams had to perform a number of tasks (e.g., scan a network or break into a host). Each task had to be completed in a limited amount of time (e.g., 30 minutes). The first team that achieved the task got the maximum amount of points. If the other team completed the task within the specified time, it received some "pity points". If the time elapsed and the team was not able to complete the task, then a cheat-sheet was provided so that the task could be completed, but no points were given. A task was disclosed only after the previous one was completed by both teams. This exercise used no virtualization and two target vulnerable network were set up by the organizers.

Fall 2003

In the fourth edition of the class we moved to a DEFCON-like setup, in which the teams were given a VMware image which presented the server to both protect and attack. The class included two exercises: one internal exercise, which was held November 14th, 2003 (Bass Tard Corp. image), and the first inter-university CTF, which was held on December 5th, 2003.

The Bass Tard Corporation

First Inter-University CTF

In this competition, thirteen teams from around the United States competed in a game of virtual capture the flag by attempting to compromise other teams' network services while trying to protect their own services from attack. This edition is known as the "Windows Open Source" exercise.

Fall 2004

In the fifth edition of the class we extended the inter-University competition to universities outside the US. As for the previous year, this edition of the class included an internal CTF. This exercise was held on November 12th, 2004 (Spam Museum image). The international CTF, aka iCTF, was held on December 3rd, 2004 (United Nations image).
